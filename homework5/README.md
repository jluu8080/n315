## Purpose

This assignment combines the individual front-end development techniques we have covered into a larger, complete project.

At this point in the course, you have worked with responsive layouts, JavaScript modules, URL-based navigation, view injection, forms, and user feedback. This project requires you to determine how those concepts should work together.

You are expected to make development decisions on your own. The prototype shows what the application should look like, while the requirements describe what it should do. You are responsible for determining how to build it using the techniques covered in class.

## Instructions

Using the supplied Summit Ridge Outfitters desktop and mobile prototypes, create the complete website.

Prototype: Summit Ridge

Your finished project must meet the following requirements:

- Your site should closely match the supplied Summit Ridge Outfitters prototypes.
- Your site must include all pages/views shown in the supplied prototype.
- Your site must include the Login and Sign Up views.
- Your site must have a consistent header/navigation and footer.
- Your site must be responsive and work appropriately at both desktop and mobile sizes.
- Use HTML, SCSS/CSS, and Vanilla JavaScript to create the project.
- Organize your JavaScript using ES modules.
- Your application should use one main HTML page and dynamically inject the appropriate view into the page.
- Navigation must be controlled through the URL using hash-based navigation.
- Changing the URL/hash should load the appropriate view.
- Refreshing the browser on a valid route should display the correct view.
- Navigation between views should not require separate HTML files.
- Login and Sign Up should function as part of the same view-injection/navigation system as the rest of the site.
- The Login form must validate the information entered by the user.
- The Sign Up form must validate required information, including matching passwords.
- A successful login should change the application to a logged-in state.
- When logged in, the Login option in the navigation should change to Logout.
- Logging out should return the application to a logged-out state.
- You are not required to use a database or external authentication service. You may simulate login and account creation in JavaScript.
- User feedback is required throughout the application. Users should never have to guess whether an action succeeded or failed.
- Appropriate feedback must be provided for actions such as successful login, logout, account creation, validation errors, incorrect login information, and other applicable interactions.
- User feedback should be visually consistent with the Summit Ridge design and should not rely solely on browser `alert()` messages.
- Use reusable functions/modules where appropriate instead of duplicating functionality.
- Images, fonts, colors, spacing, typography, and other visual elements should closely follow the supplied prototype.
- Your project should be organized using appropriate folders and meaningful file names.
- Your finished project must run without JavaScript errors in the browser console.
- Upload the completed project to the Web 4 server and GitHub.
- Submit your GitHub repository link for grading.

This is a two-week project. You are expected to use the techniques demonstrated in class, previous assignments, course examples, and the supplied prototype to determine how to complete the requirements.
